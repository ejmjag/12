01 · Кіріспе

Conditional Sentences деген не?

Conditional сөйлем екі бөліктен тұрады: if-clause (шарт) және main clause (нәтиже). If басында тұрса, екі бөліктің арасына үтір қойылады. If ортасында тұрса, әдетте үтір қойылмайды.

If + шарт, нәтиже / Нәтиже + if + шарт

If it rains, we stay inside.

Егер жаңбыр жауса, біз үйде қаламыз.

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

We will stay inside if it rains.

Жаңбыр жауса, біз үйде қаламыз.

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

02 · Zero Conditional

Zero Conditional — заңдылық пен факт

Тұрақты шындық, ғылыми факт, әдет, бір жағдай қайталанғанда үнемі болатын нәтиже. Екі бөлікте де көбіне Present Simple қолданылады. Кейде if орнына when қолдануға болады, егер әр орындалған жағдайда нәтиже болатын болса.

If + Present Simple, Present Simple

If you heat ice, it melts.

Мұзды қыздырсаң, ол ериді.

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

If I drink coffee at night, I cannot sleep.

Түнде кофе ішсем, ұйықтай алмаймын.

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

When the sun sets, it gets dark.

Күн батқанда қараңғы түседі.

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

03 · Zero: болымсыз және сұрақ

Zero Conditional формалары

Болымсыз сөйлемде do not / does not қолданылады; be етістігімен am not / is not / are not. Сұрақты main clause бөлігінде do/does немесе be арқылы құрастыруға болады.

If + S + do/does not + V1, S + V1(s)

If you do not water plants, they die.

What happens if you mix blue and yellow?

If the temperature is below zero, water freezes.

04 · First Conditional

First Conditional — нақты болашақ мүмкіндік

Болашақта орындалуы мүмкін шарт және соның ықтимал нәтижесі. If бөлігінде болашақ мағынада әдетте will қолданылмайды: Present Simple, ал нәтижеде will + V1. Нәтижеде can, may, might, must, imperative да келе алады.

If + Present Simple, will + V1

If I study, I will pass the exam.

Дайындалсам, емтиханнан өтемін.

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

If it rains tomorrow, we will stay home.

Ертең жаңбыр жауса, үйде қаламыз.

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

If you finish early, you can leave.

Ерте аяқтасаң, кете аласың.

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

05 · First: сұрақ және болымсыз

First Conditional формалары

Шарттың болымсыздығы: if + do/does not + V1. Нәтиженің болымсыздығы: will not (won’t) + V1. Сұрақта will сөйлемнің басына шығады. If бөлімінде will кейде ерік/сыпайы өтініш мағынасында кездеседі, бірақ әдеттегі болашақ шарт үшін Present Simple қолданылады.

If + Present Simple, will / won’t + V1

If she does not hurry, she will miss the bus.

Ол асықпаса, автобустан қалып қояды.

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

If I have time, I won’t be late.

Уақытым болса, кешікпеймін.

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

Will you help me if I ask?

Сұрасам, маған көмектесесің бе?

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

06 · Балама формалар

Can / May / Might / Imperative

First Conditional нәтижесінде тек will емес, мүмкіндікке қарай can, may, might немесе бұйрық рай қолданылады. Шарттың өзінде Present Continuous не Present Perfect қолданылуы мүмкін: егер мағынасы сәйкес келсе.

If + Present tense, modal / imperative + V1

If you see her, tell her the news.

Оны көрсең, жаңалықты айт.

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

If we leave now, we may arrive on time.

Қазір шықсақ, уақытында жетуіміз мүмкін.

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

If you have finished, you can go.

Аяқтаған болсаң, кете аласың.

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

07 · Unless / When / As soon as

Уақыт және шарт жалғаулықтары

Unless = if ... not («егер ... болмаса»); unless-тен кейін әдетте қосымша not қоймаймыз. When және as soon as болашақ оқиғаға қатысты болса да, бағыныңқы бөлікте Present Simple қолданылады. Unless әрқашан if not-тың барлық контекстінде алмастырғыш емес.

Unless + Present Simple, will + V1

Unless you study, you will fail.

Дайындалмасаң, өте алмайсың.

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

As soon as she arrives, I will call you.

Ол келе салысымен, саған хабарласамын.

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

When I get home, I will rest.

Үйге жеткенде демаламын.

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

08 · Салыстыру

Zero vs First Conditional

Zero — үнемі болатын нәтиже, факт немесе әдет. First — болашақтағы нақты мүмкіндік және ықтимал нәтиже. Екеуінде де if бөлігінде Present Simple болуы мүмкін; негізгі айырмашылық — мағына мен нәтиже бөлігіндегі шақ.

Zero: If + Present, Present | First: If + Present, will + V1

If you press this button, the machine starts.

Бұл түймені бассаң, құрылғы іске қосылады (әрдайым).

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

If you press this button, the machine will start.

Бұл түймені бассаң, құрылғы іске қосылады (нақты болашақ жағдай).

Сөйлемнің шарт бөлігі мен нәтижесін салыстыр. Қолданылған шаққа және мағынаға назар аудар.

09 · Қосымша ереже

If vs When — шарт пен уақыт

If + Present Simple → мүмкін шарт; When + Present Simple → оқиға болатыны күтіледі

If белгісіз шартты білдіреді: оқиға болуы да, болмауы да мүмкін. When оқиғаның болатынын болжап, оның қашан орындалатынын көрсетеді. Zero Conditional-да қайталанатын фактіні сипаттағанда екеуі кейде алмастырылады. First Conditional-да мағына айырмашылығы сақталады.

Есте сақта: Әр мысалдағы шарт пен нәтиженің мағынасына назар аудар. КТ тапсырмаларында ұқсас нұсқалар арасындағы айырмашылық маңызды.

If she calls, I will answer.

Егер ол қоңырау шалса, жауап беремін (шалуы белгісіз).

When she calls, I will answer.

Ол қоңырау шалғанда жауап беремін (шалатынын күтемін).

If you heat ice, it melts.

Мұзды қыздырсаң, ериді — жалпы заңдылық.

10 · Қосымша ереже

Unless және If ... not — айырмашылық

Unless + positive verb ≈ If + negative verb

Unless «егер ... болмаса» деген шартты береді: Unless you hurry, you will miss the train. Көп жағдайда unless-тен кейін тағы not жазылмайды. Алайда unless барлық if not сөйлемдерін алмастыра алмайды: I will be surprised if he does not come сөйлеміндегі if not сөйлеушінің таңдануын білдіреді; unless нұсқасы мағынаны өзгертуі мүмкін. Unless — except if дегенге жақын.

Есте сақта: Әр мысалдағы шарт пен нәтиженің мағынасына назар аудар. КТ тапсырмаларында ұқсас нұсқалар арасындағы айырмашылық маңызды.

Unless you leave now, you will be late.

Қазір шықпасаң, кешігесің.

If you do not leave now, you will be late.

Қазір шықпасаң, кешігесің.

I will go unless it rains.

Жаңбыр жаумаса, барамын.

11 · Қосымша ереже

Provided that / As long as / On condition that

provided (that) / providing (that) / as long as / on condition that + clause

Бұл тіркестер шарттың орындалуы маңызды екенін білдіреді. Provided (that) және providing (that) — «мына шартпен»; as long as — «тек ... болса / ... болған жағдайда»; on condition that — ресми «... шартымен». Болашақ мағынада осы бағыныңқы сөйлемдерде әдетте Present Simple қолданылады. As long as уақыт ұзақтығын да білдіре алады; мағынаны контекст анықтайды.

Есте сақта: Әр мысалдағы шарт пен нәтиженің мағынасына назар аудар. КТ тапсырмаларында ұқсас нұсқалар арасындағы айырмашылық маңызды.

You can borrow my laptop provided that you return it tonight.

Ноутбугымды бүгін кешке қайтару шартымен ала аласың.

We will go hiking as long as the weather is good.

Ауа райы жақсы болса ғана серуенге шығамыз.

You may enter on condition that you show your ID.

Жеке куәлігіңді көрсетсең ғана кіре аласың.

12 · Қосымша ереже

In case vs If — сақтық және шарт

in case + Present Simple ≠ if + Present Simple

In case «... болып қалуы мүмкін болғандықтан, алдын ала сақтық жасау» мағынасын береді. If шарт орындалғанда ғана жасалатын әрекетті білдіреді. In case of + noun — «... болған жағдайда» (ресми нұсқа). Болашақтағы жағдай туралы айтқанда in case бағыныңқысында әдетте Present Simple қолданылады.

Есте сақта: Әр мысалдағы шарт пен нәтиженің мағынасына назар аудар. КТ тапсырмаларында ұқсас нұсқалар арасындағы айырмашылық маңызды.

Take an umbrella in case it rains.

Жаңбыр жауып қалуы мүмкін, сондықтан қолшатыр ала шық.

Take an umbrella if it rains.

Жаңбыр жауса ғана қолшатыр ал.

In case of fire, use the stairs.

Өрт болған жағдайда баспалдақты пайдаланыңыз.

13 · Қосымша ереже

Before / After / Until / By the time / Once

When / before / after / until / as soon as / once / by the time + present tense

Болашақтағы уақыт бағыныңқыларында will орнына әдетте Present Simple немесе мағынасына қарай Present Perfect қолданылады. Before — бұрын; after — кейін; until — ... дейін жалғасу; once — ... болған соң; by the time — ... кезге қарай. Негізгі сөйлемде will болуы мүмкін.

Есте сақта: Әр мысалдағы шарт пен нәтиженің мағынасына назар аудар. КТ тапсырмаларында ұқсас нұсқалар арасындағы айырмашылық маңызды.

I will call you after I finish the lesson.

Сабақты аяқтағаннан кейін саған хабарласамын.

Wait until she arrives.

14 · Қосымша ереже

If бөлігінде will — қашан рұқсат?

If + Present Simple (әдеттегі шарт); if + will (ниет/сыпайы өтініш)

Қалыпты First Conditional-да If it rains, we will stay home деп айтамыз, if it will rain емес. Бірақ will болашақ шақты емес, адамның ниетін, келісімін, қалау білдіруін немесе сыпайы өтінішті көрсетсе, if бөлігінде кездесе алады. Мысалы, If you will wait here, I will call the manager — «осында күте тұрсаңыз». If + will болашақ туралы жанама сұрақта да мүмкін: I do not know if it will rain — мұнда if «ма/ме» деген мағынада, шарт емес.

Есте сақта: Әр мысалдағы шарт пен нәтиженің мағынасына назар аудар. КТ тапсырмаларында ұқсас нұсқалар арасындағы айырмашылық маңызды.

If it rains, we will cancel the trip.
